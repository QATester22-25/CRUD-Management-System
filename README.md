
# Product Management System — LocalStorage Version

A responsive product management and sales application built with HTML, CSS, and vanilla JavaScript. This version uses the browser's `localStorage` to persist data without a backend or database.

## Features

- **Product management:** Create, read, update, and delete products.
- **Product search:** Search products using available product information.
- **Inventory management:** Track product quantities and stock levels.
- **Sales management:** Search for products, calculate sale totals, and update stock quantities.
- **Discount management:** Apply discounts and calculate discounted prices.
- **Data persistence:** Store product data in the browser's `localStorage`.
- **User interface:** Manage products, inventory, and sales through a browser-based interface.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
- Browser localStorage

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/QATester22-25/CRUD-Management-System.git
   ```

2. Open the project folder in VS Code.
3. Open `index.html` using the Live Server extension, or open the file directly in your browser.
4. Start adding products and testing the CRUD and sales features.

No Node.js server or MySQL database is required for this version.

## Data Storage

Product data is stored in the browser's `localStorage`. Data is specific to the browser and origin used by the application. Clearing browser storage may permanently remove the saved data.

## Project Purpose

This version demonstrates DOM manipulation, JavaScript events, CRUD operations, search functionality, calculations, and client-side data persistence.
